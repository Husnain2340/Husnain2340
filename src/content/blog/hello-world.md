Welcome to my blog! I've wanted a place to write things down for a while, and this is it.

## What to expect

I'll mostly write about three things:

- **Software engineering**: things I build, bugs I fix, and tools I like.
- **Data & analytics**: queries, dashboards and lessons learned working with data.
- **Career & learning**: how I learn, what I'm reading, and what's working for me.

## How this site works

The blog is built with [Astro](https://astro.build). Each post is a Markdown file in
`src/content/blog/`. Pushing to `main` rebuilds and deploys it to GitHub Pages automatically.

Thanks for stopping by. There's an [RSS feed](../../rss.xml) if you'd like to follow along.
